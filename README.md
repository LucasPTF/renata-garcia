# Renata Garcia

Página de vendas do workshop Seu Primeiro Negócio Digital, da Carreira Profissional Prime.

## Rotas

- `/a1`: ângulo de dor e nova saída
- `/a2`: ângulo de quebra de crença
- `/a3`: ângulo de resultado e quebra de objeção
- `/obrigado`: orientações depois da compra ou inscrição

As três versões de vendas usam a mesma estrutura, oferta e identidade visual. Somente a hero muda entre os ângulos.

## Execução local

1. Instale as dependências com `npm install`.
2. Inicie o ambiente local com `npm run dev`.
3. Gere a versão de produção com `npm run build`.
4. Execute a validação automatizada com `npm test`.

## Checkout

Defina `NEXT_PUBLIC_CHECKOUT_URL` com o endereço final do checkout. Enquanto essa informação não estiver configurada, os botões usam o atendimento oficial da CPP no WhatsApp.

Não adicione credenciais, senhas ou dados locais ao repositório.
